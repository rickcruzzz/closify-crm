## 🎯 O QUE É

Sistema de CRM para PME de serviço no Brasil que vende por orçamento. Você conecta seu WhatsApp, coloca tudo que chega de cliente ali, organiza, e não esquece de ninguém.

## 💎 FEATURES COMPLETAS

### 1. KANBAN DE VENDAS
- ✅ Coluna: Novo, Cotado, Proposta, Negociado, Fechado, Perdido
- ✅ Arrasta conversa entre colunas (drag-and-drop)
- ✅ Cada card mostra: cliente, valor, quando entrou, quem tá cuidando
- ✅ Filtro por: cliente, valor, data, responsável
- ✅ Multi-empresa: cada um vê só seu funil

## 📱 COMO USAR - ROTINA DO DIA A DIA

**Manhã:**
1. Abre Velo
2. Painel "Hoje" mostra tudo que vence hoje
3. Manda mensagem pro cliente (via WhatsApp, manualmente)

**Durante o dia:**
1. Cliente manda orçamento no WhatsApp
2. Aparece automático no Kanban
3. Você arrasta pra "Proposta"
4. Sistema avisa daqui 3 dias pra cobrar

**Noite:**
1. Vê dashboard: quantas vendas fechou hoje
2. Prepara tarefas pro dia seguinte
3. Dorme tranquilo (não vai esquecer ninguém)
